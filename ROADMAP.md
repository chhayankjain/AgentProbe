# Roadmap

The live roadmap is the pinned GitHub issue:
**https://github.com/chhayankjain/AgentProbe/issues/38**

It groups open work into:

- **v1.2 — Broader fault coverage:** orchestration (#24) and context-degradation (#25) injectors in a real experiment, semantic corruption for malformed output (#28), correlated/bursty injection (#27).
- **v1.3 — Framework and model expansion:** cloud LLM APIs with native function calling (#26), CrewAI (#32) and OpenAI Agents SDK (#33) adapters, multi-seed runs (#34).
- **Infrastructure and quality:** strict mypy (#29), coverage (#30), Grafana dashboards (#31), JSON Schema for outputs (#35), integration tests (#36), PyPI publishing (#37).

If you want to pick something up, comment on the linked issue or open a new one. Issues labelled `good first issue` and `contributions welcome` are the best entry points.

> **Historical note:** before v1.0 this file held a chunk-by-chunk build plan. Every chunk in that plan has shipped; see `ARCHITECTURE.md` for the current module layout.
